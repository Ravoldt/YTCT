YouTube Comment Toolkit Privacy Policy

Effective November 22, 2026

YouTube Comment Toolkit helps you read, search, export, and ask questions about comments on YouTube videos and community posts. The extension has no developer-operated backend, advertising, analytics, or tracking. The developer does not receive your browsing activity, exports, conversations, or API keys through the extension.

YouTube activity and exports

On supported YouTube pages, the extension reads the current video or post identifier, title, and playback position, and can read comment responses YouTube already loads. When you choose Collect, use the page’s download button, or enable automatic collection after page load in Settings, the extension can request additional comments and replies from YouTube using the page’s existing session. YouTube receives those requests and may receive your YouTube session cookies as part of normal browser operation. The extension does not copy browser cookies or passwords into its storage, exports, or assistant prompts.

Collected data can include video or post metadata, comment and reply text, commenter names and channel identifiers, avatar links, timestamps, and engagement counts. The extension uses this information to display, search, and export comments. It can fetch avatars and source images from YouTube’s Google-hosted image services. If you import a Markdown or JSON export, the extension reads that file to make it available to the same features. Downloaded files are saved to your device at your request.

Assistant requests and API keys

Ask is optional. Before the first request for a destination on a visit, the extension shows the configured endpoint and the types of information the request can include. If you proceed, the selected endpoint receives your question, relevant earlier turns for the same profile and destination, and a selection of YouTube or imported material. This may include the source link, title, comment text, and commenter names. Video captions are included only if you enable the transcript setting. Ollama prompts can also include a thumbnail or post images.

Depending on your selection, recipients can include your own Ollama, Open WebUI, llama.cpp, LM Studio, or custom server, or a service you choose such as OpenAI, Anthropic, Google Gemini, OpenRouter, DeepSeek, Groq, Mistral, xAI, Together AI, Fireworks AI, Cerebras, SambaNova, Nebius, Perplexity, Moonshot, or Z.AI. A server on your device can forward requests to a cloud provider. The endpoint operator and any service it routes to handle data under their own terms and retention policies.

If you enter an API key, the extension saves it in this browser profile’s extension storage and sends it to its configured endpoint to authenticate model requests and connection checks. Load models makes a model-list request. Test can send a short sample prompt. These checks do not send the current comments or chat history. Keys are not synced and are not encrypted by the extension at rest. The extension uses HTTPS for non-loopback endpoints.

Retention and controls

  • Keeping copies of exports in browser storage is off by default. If you enable it, the default retention is up to seven days, with earlier removal of unused entries or entries that exceed the cache budget. You can change the limits or choose Settings → General → Clear saved exports to remove saved copies.
  • Chat history is stored for the current visit in browser session storage. You can clear it with Clear chat. A change of source or assistant destination starts a separate conversation. Captions fetched for Ask are held in memory.
  • To remove a saved API key, choose Clear key and save, or delete the profile. You can revoke optional host permissions in your browser’s extension settings. Removing the extension deletes its browser storage. Downloaded files, clipboard copies, and data already sent to a provider are managed separately.

The extension is unavailable in private/incognito browsing windows.

Limited Use

YouTube Comment Toolkit’s use and transfer of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. The developer does not sell user data or use it for advertising, creditworthiness, or lending.
